# KCIM 출산·육아 응대 가이드

경영관리본부 담당자가 임신·출산·육아 관련 제도를 단계별로 안내하고, 법정 기간을 자동 계산하며, AI 챗봇에게 실시간으로 질의할 수 있는 Streamlit 기반 내부 업무 지원 도구입니다.

- 기준 시점: **2026-08** (노무법인 인화 매뉴얼 2026.03 1판 + 2026년 8~9월 시행 개정사항 반영)
- 배포 대상: KCIM 경영관리본부 내부 (일반 직원 응대용이 아닌, **담당자용 업무 가이드**)

---

## 1. 주요 기능

### 1) STEP 가이드 (총 9단계)

| STEP | 이름 | 내용 |
|---|---|---|
| 0 | 임신 확인 | 임신 확인 및 초기 응대, 비밀유지 |
| 1 | 임신기 단축 | 근로시간 단축(12주 이내/32주 이후), 출퇴근시간 변경, 쉬운 근로 전환 |
| 2 | 건강진단 | 태아검진시간 부여 |
| 3 | 연차 정리 | 출산휴가 전 연차 사용 안내 |
| 4 | 출산 관련 | 출산전후휴가, 배우자 출산(전후)휴가, 유산·사산휴가 |
| 5 | 육아 지원 | 육아기 근로시간 단축, 육아시간(수유시간) |
| 6 | 복직 준비 | 육아휴직, 단기 육아휴직, 6+6 부모육아휴직제, 복직 관리 |
| 7 | 가족돌봄 | 가족돌봄휴직·휴가 |
| 8 | 난임치료 | 난임치료휴가 (참고 항목으로 맨 뒤 배치) |

각 STEP은 담당자 스크립트, 체크리스트, 필요 서류/주의사항, 관련 법령, 핵심 수치(KPI), FAQ로 구성됩니다.

### 2) 계산기 도구 (3종)

- **임신기 단축 기간 계산기**: 출산예정일 입력 → 12주 이내/32주 이후 단축 가능 구간 자동 산출
- **출산·육아 일정 계산기**: 연차·출산휴가·육아휴직 기간을 표로 입력 → 합산 일수, 잔여 육아휴직 자동 계산
- **무급휴가 연차삭감 계산기**: 무급휴가 기간 입력 → 80% 출근율 기준 연차 삭감 여부·일수 자동 계산

### 3) AI 챗봇 "육아지원박사"

- 현재 보고 있는 STEP의 체크리스트·법령을 시스템 프롬프트에 자동 반영해 맥락에 맞는 답변 제공
- OpenAI `gpt-4o` 스트리밍 응답
- 확실하지 않은 세부 수치는 "노무사 확인 권장"으로 안내하도록 지시됨

## 2. 실행 방법

```bash
pip install streamlit openai pandas
streamlit run app.py
```

### 필요 secrets (`.streamlit/secrets.toml`)

```toml
OPENAI_API_KEY = "sk-..."
```

`OPENAI_API_KEY`가 없으면 STEP 가이드·계산기는 정상 동작하며, 챗봇 질의 시에만 오류 메시지가 표시됩니다.

## 3. 법령 반영 현황 및 확인 필요 사항

### 이미 시행 중 (2026-08 기준 확정 반영)

- 임신기 근로시간 단축: 12주 이내 / 32주 이후, 1일 최대 2시간
- 배우자 출산휴가: 20일(근무일 기준), 3회 분할
- 육아휴직: 기본 1년 + 조건부 6개월(부모 각각 3개월+ 사용 또는 한부모·중증장애아동 부모) = 최대 1년 6개월
- 육아휴직 사후지급금 폐지 (매월 전액 지급)
- 6+6 부모육아휴직제: 자녀 생후 18개월 이내 부모 동시/순차 사용 시 첫 6개월 통상임금 100%
- 난임치료휴가: 연 6일(최초 2일 유급)
- 가족돌봄휴직·휴가: 연 90일(휴가 연 10일 포함)
- 단기 육아휴직(2026-08-20 시행): 만 8세 이하 자녀 단기 돌봄 시 연 1회 1~2주 단위

### 시행 예정 (2026-09-18, 코드에 "시행 전" 명시 반영됨)

- 배우자출산휴가 → "배우자출산전후휴가" 명칭 변경, 출산예정일 50일 전부터 사용 가능하도록 확대
- 배우자 유산·사산휴가 신설 (5일, 최초 3일 유급)
- 배우자 유산·조산 위험 시 남성 근로자 출산 전 육아휴직 사용 확대

### 최종 확인 필요

- 단기 육아휴직 관련 세부 내용은 언론·자문 블로그 기반으로, **법령 원문·시행령 고시로 직접 재확인 필요**
- 육아휴직 급여 상한액 등 수치는 노무법인 인화 매뉴얼(2026.03) 기준이며, **배포 전 노무사 최종 확인 권장**

## 4. 파일 구조

```
kcim_guide/
├── app.py          # 메인 Streamlit 앱 (단일 파일)
└── README.md        # 본 문서
```

`STEPS` 리스트(app.py 상단)에 모든 콘텐츠(스크립트, 체크리스트, 법령, FAQ 등)가 딕셔너리로 정의되어 있어, 내용 수정 시 해당 STEP의 딕셔너리만 편집하면 됩니다.

## 5. 최근 변경 이력

- STEP 0(난임치료휴가)를 맨 마지막 STEP 8로 이동, id 재정렬
- 단기 육아휴직(2026-08-20 시행) 관련 안내를 STEP 6(복직 준비)에 반영
- 챗봇 사용자 메시지 렌더링 누락 버그 수정 (질문 입력 즉시 화면에 표시되도록 수정)
- 챗봇 아바타를 이모지(🙋/🎓)로 고정 — 외부 이미지 요청 실패로 인한 깨진 아이콘 표시 문제 해결
